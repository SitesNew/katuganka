:: Назначение скрипта ::
WR-Golos - Скрипт голосования, с возможностью администрирования, создания и переключения до 9 различных тем голосований. Скрипт в качестве БД использует файлы. Простая структура данных позволяет легко и быстро установить/перенести скрипт без потери данных в любую папку как на сервере, так и на другой сайт. Размер скрипта: 59 Кб.
Пример: Голосование посетителей сайта WR-Скрипт.РУ. Скачать скрипт WR-Golos можно: по этой ссылке.
:: Возможности ::
    - возможность сформировать до 9 разных тем голосования;
    - блокировка по IP - запрет повторного голосования;
Админитерфейс с возможностью:
    - АНТИФЛУД - чаще указанного времени голосовать запрещено. Время задаётся (0-999) сек.
    - ввод в админке до 9-и ответов на каждое из голосований;
    - редактирование текущих голосований;
    - выбора папки для сбора данных;
    - получения кода голосования для его последующей установки на html-страницу;
    - получения кода голосования для его последующей установки на php-страницу.

Изменения в новой версии:
- скрипт сконвертирован в UTF-8 кодировку для корректного встраивания на Вашу php-страницу;

- изменён дизайн. Все таблицы переведены в div'ы и добавлен файл стилей style.css;

- данные сконвертированы в csv-формат который легко открыть в Excel/Calc или в блокноте;

- доработан и улушен блок авторизации в панель администрирования логин и пароль теперь admin, можно менять;

:: Установка и использование ::
1. Создайте папку на Вашем сервере, например "golos". Подключитесь к серверу по FTP и закачайте в эту папку все файлы и каталоги.
Выставите ей атрибуты Chmod 755
Закачивать и настраивать атрибуты скрипта можно менеджером "Total Commander".(Файл -> Изменить атрибуты).
2. Далее указан состав скрипта и права доступа, которые необходимо выставить файлам и папкам:
Файлы / описаниеПрава доступа
  • index.php - пример файла запуска голосований;
    		• 755
  • vote.php - модуль голосования;
  • rezult.php - результаты голосования;
  • admin.php - модуль администратора;
  • папка "images" - с графическими файлами (4 шт.);
  • папка "g1" - с рисунками (3 шт.);
  • README.html - этот файл;
    		• -
  • папка "data" - с данными голосований;
    		•  666 / 644
    или 777
  • config.php - файл с настройками.

    • 3. Данные права доступа используются на большинстве серверов. В случае, если скрипт не запускается и выводится ошибка "Permise Denied" - скорее всего Вы неверно установили права или что то сделали не так.
    Можете посмотреть статью по настройке прав доступа.
    Если скрипт не заработал, не бойтесь экспериментировать: изменяйте атрибуты каталогов и файлов.
    Иногда, на "сомнительном" хостинге, скрипт запускается с атрибутами 777 (вместо 755) и 666 (вместо 644) для файлов и папок соответственно согласно таблице. Либо 777 для всех файлов.
    4. Попытайтесь запустить скрипт ссылкой такого типа: http://Мой_сайт/golos/index.php.
    Для того, чтобы включить счётчик на Вашу страницу, достаточно инклюдить его код на любую Вашу php-страницу.
    Админпанель запускайте ссылкой вида: http://Мой_сайт/golos/admin.php. Логин и пароль по-умолчанию admin.
    5. Ваш отзыв или предложения по модернизации скрипта можете оставлять на форуме.
    Если все пункты вы выполнили, а скрипт так и не запустился, ну чтож, заходите на форум по WR-Скриптам и в разделе "WR-Script / WR-Golos" просмотрите темы, возможно решение Вашей проблемы уже есть на форуме. Если нет - задавайте вопросы. Постарюсь Вам помочь.
